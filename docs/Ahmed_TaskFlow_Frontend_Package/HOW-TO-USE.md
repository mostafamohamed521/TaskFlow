# How to Use the Ahmed Prompt Package

1. Read `README.md` before using any individual prompt.
2. Choose a screen by number, 01–14.
3. Send the corresponding file from `01-UI-Design-Prompts` to your image/design system along with the original TaskFlow logo/brand reference and approved App Shell visuals.
4. Review the design for correct permissions, content and responsive potential.
5. Supply that approved screenshot, the full existing frontend source, and the matching prompt in `02-Frontend-Implementation-Prompts` to your coding tool.
6. Require implementation in the documented HTML/CSS/JS paths and a screenshot comparison plus QA report.
7. Continue in order and keep data/services shared rather than generating an isolated mock state per page.
